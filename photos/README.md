# photos/

Put your daily photos here, named by day number:

```
001.jpg   ← 12 Aug 2026, day 1
002.jpg   ← 13 Aug 2026, day 2
...
297.jpg   ←  4 Jun 2027, day 297, the last one
```

Then list the day in `../photos.js`. A photo sitting in this folder does
nothing until it's in the manifest.

Keep each file under about 500 KB — resize the long edge to ~1600px before
saving. 297 photos at phone-camera size would make the page painfully slow to
load for your classmates.
